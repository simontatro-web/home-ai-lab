# careerfieldnotes.com

[careerfieldnotes.com](https://careerfieldnotes.com) is my site. The home
server does the data work behind it: it analyzes the site's data and helps
me sort the collected data and the quotes from people into the categories
the site is organized around.

Running this on my own hardware instead of a paid API means the data stays
on my machine and there's no per-request cost.
